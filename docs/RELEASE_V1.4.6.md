# Pixel Codex V1.4.6 修正内容要約

V1.4.6は、開発フロアのドット絵表現とキャラクター移動をまとめて整える品質改善リリースです。
オフィスを見やすくするだけでなく、今後キャラクターを追加しても同じ品質を保てる制作規格と
変換工程まで更新しています。

## 主な変更

### キャラクターグラフィック

- Manager / Scout / Builder / Checkerの4系統へ役割別の髪型、服、小物、シルエットを追加
- Manager系へ実画像の256×256スプライトシートを導入
- 名簿アイコンとフロアキャラクターが、担当と服色を含めて同じ素材を使用するよう統一
- 正面・左・右・背面の4方向と、直立・大股A・中間・大股Bの4コマを標準化
- 左移動時に右向き画像が表示されていた方向割り当てを修正

### 歩行と接地感

- 移動中に腕と脚を逆位相で振り、横向きでは両脚が前後に分かれる歩行へ変更
- 全16コマの頭頂と足元を同じ基準線へ固定し、上下移動時・左右移動時の跳ねを解消
- 身体全体を上下させる処理を廃止し、手足の差分だけで歩行を表現
- 大きな楕円影を、靴へ重なる薄いハードエッジ接地影へ変更
- 移動を260ms/タイル、アニメーションを8fpsへ調整
- 1マスにつき片足を1回踏み出し、2マスで左右1周期になるよう移動距離と歩数を同期
- 机へ到着した後は経路の最終方向を向き続けず、机・会議卓・カウンター側へ向き直るよう修正

### オフィスグラフィック

- 2pxグリッドと共通パレットを床・壁・家具へ適用
- 床板の差分、壁の明るい縁と右下影、家具の接地影を追加
- 机、椅子、会議卓、棚、通信設備などの天板・正面・側面と小物を描き分け
- 背景、家具、キャラクターのコントラストを整理し、状態表示と移動経路を読みやすく改善

## 制作工程

- `assets/sprites/manager-sheet.png`を4列×4行の標準シートへ更新
- `tools/build_manager_sheet.py`で参照画像から2pxグリッドの実シートを再生成可能
- `tools/spriteforge.html`を256×256・4方向×4コマ・8fpsプレビューへ更新
- [Pixel Codex アート規格](pixel-art-direction.md)と
  [キャラクタースプライトの作り方](sprite-guide.md)を現行実装に合わせて更新
- PNGをwebpackの`asset/resource`として同梱する読み込み経路を追加

## 修正の背景

従来は、方向ごとの画像配置、歩行フレーム、移動速度が別々に決まっていました。そのため、
左右の向き違い、到着後に机を向かない、歩数と移動距離が合わず滑って見える、身体全体が上下して
浮いて見える、といった問題が発生していました。

V1.4.6では、スプライトの行列、接地線、再生順、フレームレート、1タイルの移動時間、停止時の向きを
共通仕様として定義し、実画像・手続き描画・変換ツールの3経路へ同じ規則を適用しています。
