# 動作環境（配布用）

Pixel Codex を他の人に配って使ってもらうときに必要な、PC側の条件をまとめています。

## 必須要件

| 項目 | 要件 |
| --- | --- |
| OS | Windows 10（64bit / build 1809 以降）または Windows 11 |
| CPU | x64。ARM64機は x64 エミュレーションでの動作見込み（未検証） |
| メモリ | 8GB 以上（16GB 推奨） |
| ストレージ | インストーラ 134MB、インストール後 約350MB。加えて Codex CLI と作業フォルダの Git 履歴の分 |
| 画面 | 1280×720 以上（ウィンドウ最小 1240×680、初期 1440×820 のため 1600×900 以上を推奨）。開発フロア図・進行表・右カラムを横に並べるため、横幅の広い画面ほど見やすくなります |
| GPU | WebGL 対応が望ましい。非対応環境では Canvas 描画へ自動的に切り替わります |
| 権限 | 管理者権限は不要。`%LOCALAPPDATA%` へユーザー権限でインストールされます |

Windows 専用です。macOS・Linux 版は配布できません。インストーラの生成が Windows 向けのみで、
Codex CLI の検出に `where.exe` と `codex.exe`、他セッションの確認に `tasklist.exe` /
`taskkill.exe` を使っているためです。

## 別途インストールが必要なもの

### Codex CLI（同梱していません・必須）

アプリは Codex CLI を次の順に探します。

1. `%LOCALAPPDATA%\OpenAI\Codex\bin\...\codex.exe`（Codex デスクトップ版のランタイム）
2. PATH 上の `codex`
3. `%APPDATA%\npm\codex.cmd` / `codex.exe`（npm でグローバル導入した場合）

条件は次のとおりです。

- `codex --version` が `codex-cli x.y.z` を返すこと
- `codex app-server` サブコマンドに対応したバージョンであること
- npm 経由で入れる場合は Node.js（v20 以降）も必要
- 事前にログインを済ませていること（ChatGPT の有料アカウント、または OpenAI API キー）

自動検出できない場合は、アプリ上部の `…` から `codex.exe` を直接指定できます。

利用料は Codex CLI 側のアカウントに課金されます。配布時はこの点も伝えてください。

### Git（任意・セーブ機能に必要）

セーブ／ロードは作業フォルダの Git コミットとして記録します。PATH 上に `git` が無い場合、
セーブ機能だけが使えません。他の機能はそのまま動作します。

## ネットワーク

- OpenAI / ChatGPT のエンドポイントへの HTTPS 通信（Codex CLI 側の通信）。
  社内プロキシやファイアウォールがある環境では、あらかじめ許可が必要です。
- `fonts.googleapis.com` / `fonts.gstatic.com`（レトロフォント DotGothic16）。
  遮断されていても MS Gothic へフォールバックして動作します。

## 配布時に伝えること

- コード署名をしていないため、初回起動時に SmartScreen の
  「WindowsによってPCが保護されました」が表示されます。
  `詳細情報` → `実行` で進めてもらってください。ブラウザのダウンロード警告も同様です。
- 自動更新はありません。更新はインストーラの再配布になります。
- 子プロセスの起動と、プロセスの列挙・強制終了を行います。EDR や AppLocker、WDAC が
  厳格な業務用 PC ではブロックされることがあります。
- Codex が作業フォルダ内のファイルを読み書きし、コマンドを実行します（実行前に承認ダイアログが
  出ます）。利用者が書き込み権限を持つローカルフォルダを選んでもらってください。
- セーブは作業フォルダに Git コミットを積み、`.pixel-codex/` フォルダを作ります。既に Git で
  管理しているフォルダを選ぶ場合は、この点を伝えてください（履歴の巻き戻しはしません）。
- UI とエラーメッセージは日本語のみです。

## 保存されるもの

| 場所 | 中身 |
| --- | --- |
| `%APPDATA%\Pixel Codex\` | 設定、雇用情報、AIモデルの選択、接続したフォルダの履歴、グローバルスキル（`skills/*.md`） |
| `<作業フォルダ>\.pixel-codex\` | セーブ情報（`save.json`）、プロジェクト専用スキル（`skills/*.md`） |
| 一時フォルダ | 指示に添えた画像。アプリ終了時に削除されます |

## 補足

メモリの数値は実測ではなく、Electron + Chromium + Phaser に Codex の子プロセスが加わる構成からの
目安です。正確な値が必要な場合は実機で計測してください。
