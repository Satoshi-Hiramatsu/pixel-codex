# キャラクタースプライトの作り方（4方向 + 歩行アニメ）

「キャラに正面・背面・左・右を表示させたい」への回答と、絵の作り方の説明です。

---

## 1. いまの仕組み

| 部品 | 役割 |
| --- | --- |
| `src/assets/agentSheet.ts` | ドット絵シートそのもの（PNG の data URI）とパレット定義 |
| `tools/spriteforge.html` | AI で描いた立ち絵を、上のファイルに焼き直す変換ツール |
| `src/game/characterSheet.ts` | シートを読み、服の色を差し替えて共有アトラスに並べる |
| `src/game/AgentSprite.ts` | 向きの決定・歩行アニメ・名前や吹き出しの配置 |

**絵をつくる → ツールに通す → `agentSheet.ts` を差し替える**。作業はこれだけです。
コード側をさわる必要はありません。

### なぜ PNG ファイルではなく data URI なのか

- 絵がまだ無くてもビルドが通る（＝先にコードを進められる）
- webpack に `asset/resource` のルールを足さなくていい
- パッケージ版でも読み込みパスの心配がない
- Phaser のローダーを経由しないので `preload()` がいらない

`AGENT_SHEET_PNG` が `null` のあいだは、`characterSheet.ts` が四角を積んだ
**仮キャラ**を描いて動きます。だから絵が無くてもアプリは普通に起動します。

### なぜ 1枚のアトラスにまとめるのか

社員の服の色ごとにテクスチャを作ると、色の数だけテクスチャが切り替わって
スプライトのバッチ描画が分断されます。そこで

- 絵は **服を白〜グレーで塗った 1枚**だけ持つ
- 社員の色は **パレット差し替え**で後から入れる
- 差し替えた結果を **1枚の共有アトラス**（`agent-atlas`）の枠に焼く

という形にしています。FC/SFC が実機でやっていたパレットスワップと同じ考え方で、
社員が何人いてもテクスチャは 1枚のままです。

## 2. フレーム規格

`src/game/characterSheet.ts` の定数がそのまま規格です。

- **1コマ**: `64px × 64px`
- **並び**: 横 3列（コマ）× 縦 4行（向き）＝ 1枚 `192px × 256px`

```
        コマ0(直立)  コマ1(右足前)  コマ2(左足前)
行0 down  [  正面  ] [   正面   ] [   正面   ]
行1 left  [   左   ] [    左    ] [    左    ]
行2 right [   右   ] [    右    ] [    右    ]
行3 up    [  背面  ] [   背面   ] [   背面   ]
```

「ぴぽや」形式や LPC（Liberated Pixel Cup）とほぼ同じ並びなので、
配布素材を持ってきても行の入れ替えだけで合わせられます。

歩行アニメは `[1, 0, 2, 0]` の順に 7fps で再生します。
2コマしか描かなくても、あいだに直立コマが入ることで自然に歩いて見えます。

### コマの中でのキャラの収まり

フロアのタイルは `TILE = 40px`（`src/game/officeLayout.ts`）です。

- キャラ本体は **幅 40px 前後・高さ 56px 前後**
- **足元をコマの下端から 4px 上**にそろえる

こうすると足元の設置面が 1マスに収まり、頭だけが上のマスへはみ出す
MOTHER2 らしい見え方になります。この位置合わせは spriteforge が自動でやるので、
AI に描かせるときは「全身が枠内に入っていれば良い」くらいで大丈夫です。

## 3. 画像生成AIで絵を作る

### 3-1. AI には 12コマ描かせない

画像生成AIは「グリッドに整列した 12コマの、同じキャラのスプライトシート」を
安定して出せません。コマ数を増やすほど破綻します。

そこで **AI に任せるのは 4枚（4方向の立ちポーズ）だけ** にして、
残りは spriteforge が決定論的に作ります。

```
 AI生成 4枚(512px)  ──▶ ①背景抜き・整列・64×64へ縮小・減色
   正面/背面/左/右        ──▶ ②立ち1コマから歩行2コマを自動生成
                        ──▶ ③agentSheet.ts を書き出し
                        ──▶ ④実行時にパレット差し替え → 共有アトラスへ
```

### 3-2. 生成のときの指定

- **サイズ**: 512×512 程度（大きめに描かせて縮めた方がきれいになります）
- **背景**: マゼンタ `#ff00ff` の単色（カラーキーとして使います）。透過PNGを出せるモデルなら透過でも可
- **構図**: 全身・直立・腕は下ろす。あおりやふかんを付けない
- **服**: 白〜淡いグレーで描かせる（あとでパレット差し替えするため）

プロンプトの雛形:

```
SNES EarthBound / MOTHER 2 overworld character sprite, front view, full body,
standing straight, arms down, flat shading, thick dark outline,
3-4 tones per material, no dithering, no gradient, no anti-aliasing,
plain magenta #ff00ff background, white shirt
```

`front view` のところを `back view` / `side view facing left` /
`side view facing right` に差し替えて 4枚そろえます。

### 3-3. 4枚のキャラを同じ人物にそろえるコツ

**まず正面を 1枚だけ生成して気に入るものを選び、それを参照画像として
（img2img / reference image / "same character as reference" 指定で）
残りの 3枚を作る**のが確実です。4枚を一度に生成させると別人になります。

左右は、片方だけ作って画像編集で左右反転してもかまいません。
（`drawFacingSide` が示すとおり、見た目の左右差は腕と顔の向きだけです）

## 4. spriteforge の使い方

`tools/spriteforge.html` をブラウザで開くだけです（ダブルクリックで可。
サーバーも npm install も不要）。

1. **左の列（直立）の 4マス**に、生成した画像をドラッグ&ドロップする
   - 右の 2列は歩行コマとして自動生成されます
   - 自分で描いたコマがあれば、そのマスに落とせばそちらが優先されます
2. **「整える」** のつまみを合わせる
   - `背景の抜き方` … カラーキーの色と許容差。抜けすぎ／残りすぎを見ながら調整
   - `キャラの高さ` … 既定 56px（上の収まり規定）
   - `色数` … 既定 12色。減らすほどレトロになります
   - `歩幅` / `脚とみなす下部` / `上下のゆれ` … 歩行コマの作りかた
3. **「服として塗り替える色をえらぶ」** で、服に使われている色をクリックして選ぶ
   - 白〜グレーの明るい色は最初から選ばれています
   - 肌や髪を選ぶと、そこまで社員の色になってしまうので注意
4. 右下の 4つのプレビューで、7fps の歩行を目で確かめる
5. **「agentSheet.ts をダウンロード」** を押し、`src/assets/agentSheet.ts` を丸ごと差し替える

### 歩行コマはどう作られているか

直立コマ 1枚から、こうやって 2コマを起こしています。

- **よこ向き**: 脚のかたまり（下から `脚とみなす下部`%）を、進む向きへ前後にずらす
- **正面・背面**: 左右の脚を交互に持ち上げる（＝脚が短くなる）
- 共通で、コマ1とコマ2の全体を `上下のゆれ` ぶん持ち上げる

`[1, 0, 2, 0]` で再生されるので、上げ→戻し→上げ→戻しの上下動が出ます。
納得できない場合は、そのコマだけ自分で描いた画像を落として上書きしてください。

## 5. 向きの決め方（実装済み）

歩く方向から自動で決めています。`AgentSprite.walkPath()` が
1マス進むごとに次のマスとの差分を見て、

```ts
if (次のマス.col > いまのマス.col) facing = 'right';
else if (次のマス.col < いまのマス.col) facing = 'left';
else if (次のマス.row > いまのマス.row) facing = 'down';
else facing = 'up';
```

としています。移動が終わったら `idle` アニメ（コマ0）に戻り、
**最後に向いていた方向のまま立ち止まります**。

席に着いたときだけ特定の向きにしたい場合は、
`officeLayout.ts` の椅子データに `facing` があるので、
到着後にそれを使って `setFacing()` を呼べば「机に向かって座る」表現になります。

## 6. さらに凝りたくなったら

- **待機モーション**: `idle` を 2コマにして 1.5fps くらいで再生すると、呼吸しているように見えます。
- **作業モーション**: `type`（キーボードを打つ）、`read`（本を読む）などの行を増やし、
  `AgentStatus` に応じて再生アニメを切り替える。行を足すだけで規格は壊れません。
- **影**: いまはスプライトとは別に楕円を描いています。シートに影を焼き込まないでください
  （重なった時に不自然になります）。
- **等倍表示**: Phaser 側で `pixelArt: true` と `roundPixels: true` を設定済みなので、
  拡大してもぼやけません。`FRAME_WIDTH` / `FRAME_HEIGHT` を変えるときは、
  `AgentSprite` の `CHARACTER_Y` / `HEAD_LIFT` / 当たり判定もあわせて調整してください。
- **社員ごとに服以外も変えたい**: `SheetPalette` に `hair` などを足し、
  `characterSheet.ts` の `buildShirtMap()` を同じ要領で増やせば対応できます。
