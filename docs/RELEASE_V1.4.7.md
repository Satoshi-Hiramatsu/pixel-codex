# Pixel Codex V1.4.7 修正内容要約

V1.4.7は、V1.4.6で確立したドット絵と歩行の品質基準を全キャラクターへ展開するグラフィック強化リリースです。従来の4系統の描き分けから、全11担当がそれぞれ専用の見た目を持つ構成へ移行しました。

## 利用者から見える変更

### 全11担当を重複しない専用デザインへ更新

- 統括、企画、調査、実装、テスト、レビュー、デザイン、経理、通信、文書、汎用へ個別の256×256 PNGスプライトシートを割り当て
- 髪型、服装、配色、手持ち道具、頭部アクセサリー、輪郭を担当ごとに描き分け
- 名簿の顔アイコンと開発フロアの歩行キャラクターで同じマスター画像を使用
- 人物名から生成する8ビット徽章を加え、同じ担当とテーマ色の人物同士も識別可能

### 歩行・停止品質を全キャラクターで統一

- 1シートを64×64ピクセルの16コマ（4方向×4コマ）に統一
- 行順を正面、左、右、背面、コマ順を直立、大股A、中間、大股Bに固定
- 全11シート・176フレームで不透明画素の頭頂をY=4、足元をY=59へそろえ、上下動や浮遊感を防止
- V1.4.6の移動距離と歩数の同期、左右方向、到着後に机を向く動作をそのまま全担当へ適用

## 実装と制作工程

- `src/assets/agentSheet.ts`で全11担当のPNGを一元管理する`AGENT_SHEET_PNGS`を追加
- `src/game/characterSheet.ts`を担当別の画像読込と手続き生成フォールバックに対応
- `src/game/AgentSprite.ts`へ人物名を渡し、個体識別用の徽章とテクスチャ更新へ反映
- `assets/concepts/characters/`へ10担当の制作参照画像と再制作用プロンプトを保存
- `tools/build_character_sheets.py`で背景除去、トリミング、減色、64×64フレームへの整列を一括実行
- 白い服を背景と誤認しないよう、外周と連結したチェッカー背景だけを除去
- 統括責任者の`manager-sheet.png`と専用生成ツールは既存基準のまま維持

## 確認項目

- `npm run typecheck`
- `npm run lint`
- `python -m py_compile tools/build_character_sheets.py tools/build_manager_sheet.py`
- 全11シートが256×256 RGBA、4列×4行、固有ハッシュであること
- 全176フレームの頭頂・足元位置が共通基準内にあること
- Windows向けElectronパッケージへ全11シートが収録されること
- `npm run make`でWindowsインストーラーとZIPを生成できること

## 互換性

既存の担当ID、移動速度、座席、歩行タイミング、統括責任者の画像形式は変更していません。担当別PNGが利用できない場合は同じ4方向×4コマ仕様の手続き生成画像へ切り替わるため、表示処理を継続できます。
