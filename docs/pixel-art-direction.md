# Pixel Codex アート規格

キャラクター、オフィス、UI 内のドット画を同じ世界に見せるための制作基準です。
配置と当たり判定は `40px` タイル、キャラクターは `64px` フレームのまま維持します。

## 1. ピクセルグリッド

- 基本描画単位は **2px × 2px**。細部も原則として偶数座標・偶数寸法で描く。
- キャラクターは `64px × 64px` のフレーム内に収める。
- キャラクターの足元はフレーム下端から `4px` 上にそろえる。
- オフィスは `40px × 40px` を1タイルとする。
- Phaser と Canvas の画像補間は無効にし、表示座標は整数へ丸める。
- 斜め線は 1:1 または 2:1 の階段状にし、半端な角度を作らない。

## 2. 色と陰影

- 全素材で輪郭色 `#1e282c` を共有する。真っ黒は使わない。
- 光源は左上。ハイライトは左上、影は右下へ置く。
- 1素材は原則として `明色 / 基本色 / 影色 / 輪郭色` の最大4段階。
- グラデーション、半透明の塗り、アンチエイリアス、ぼかしは禁止。
- ディザリングは床などの広い面にも使わず、少数のタイル差分で質感を出す。
- キャラクターと操作対象は背景より明度差を強くする。

## 3. キャラクター

- シートは横4列・縦4行の `256px × 256px`。方向は `down / left / right / up`。
- 各行は `[直立, 大股A, 足をそろえる中間姿勢, 大股B]` の順にする。
- 歩行は `[大股A, 中間, 大股B, 中間]` を8fpsで再生する。
- 全16コマで頭頂と足元の基準線を固定し、身体全体を上下させない。
- 横向きは両脚を前後へ分離し、正面・背面は片脚を短くして踏み出しを表現する。
- 腕は脚と逆位相で振り、1マスにつき片足1回の歩数へそろえる。
- 各人物は服色だけでなく、髪型・前髪・肌・ズボン・職種小物のうち2項目以上を変える。
- 顔の目鼻より、頭部と装備のシルエットを優先する。
- 左右反転できる装飾と、利き手・分け目など反転できない装飾を区別する。
- 待機・作業アニメーションは1～2ドットの変化を2～3コマで表現する。
- 接地影は靴へ重なる不透明なハードエッジ形状とし、大きなぼかし影を置かない。

## 4. オフィス

- 描画順は `床 → 壁 → 家具の影 → 家具 → 小物 → キャラクター → UI`。
- 床は基本色に加え、明暗2種類の差分タイルを低密度で配置する。
- 壁には外周、内側の明るい縁、右下の影を持たせて厚みを出す。
- 家具は天板・正面・右側面の3面を描き、右下へ `2～4px` の影を落とす。
- 各部屋には用途を示す専用小物を最低2種類置く。
- 通路とキャラクター周辺には小物を置きすぎず、経路と状態表示を読みやすく保つ。

## 5. 受け入れ基準

- 100%表示で輪郭がにじまず、2pxグリッドの太さが不規則にならない。
- キャラクターは名前と服色を隠しても、髪型・装備・シルエットで担当を判別できる。
- 同じ担当の人物には名前由来のピクセル徽章を付け、担当・服色が同じでも完全に同じ絵にしない。
- 統括、企画、調査、実装、テスト、レビュー、デザイン、経理、通信、文書、汎用の11担当を別デザインに保つ。
- 4方向すべてで同一人物に見える。
- 左右移動で顔の向きが進行方向と一致する。
- 歩行中も全コマで少なくとも片足が接地線へ届き、身体が上下に跳ねない。
- 作業席へ到着後は、机・会議卓・カウンター側を向く。
- 家具はラベルなしでも種類を判別できる。
- 部屋はアクセント枠を隠しても用途を推測できる。
- 家具の見た目を変更しても `officeLayout.ts` の当たり判定と一致する。
