# Pixel Codex

Codexの親エージェントとサブエージェントを、ピクセルオフィス上で可視化・操作するWindows向けデスクトップクライアントです。

## 現在のMVP

- Electronから`codex app-server`を標準入出力で起動
- App Serverのスレッド、ターン、ツール、承認、完了イベントを受信
- Phaser製オフィス内でエージェントの状態に応じて移動
- React製のエージェント一覧、詳細、イベントログ
- AIの進捗報告・最終回答・質問を表示する会話パネル
- 各キャラクター上の、現在の作業や発言を示す吹き出し
- 作成・更新されたファイルと完了報告をまとめる、学校の黒板風の成果物ボード
- 成果物を既定アプリで直接開く機能と、作業フォルダを階層表示するプロジェクト図書館
- おすすめ人材の雇用、オリジナル人材作成、雇用チーム確認ができる社員名簿
- 企画一郎、絵描大好など、担当業務を連想できる固有のエージェント名
- WORKSPACE変更時のApp Server切断と、新しいフォルダへの自動再接続
- 正常に接続した作業フォルダの履歴保存と、次回起動時の最新フォルダ復元
- 作業フォルダ選択と親スレッド作成
- 新規タスク、実行中ターンへの追加指示、停止
- コマンド／ファイル変更の承認・拒否ダイアログ
- Codex未接続時のデモ表示

表示するのは状態、計画、ツール操作、変更、進捗です。モデルの内的思考は表示しません。

## 開発

```powershell
npm install
npm start
```

```powershell
npm run package
npm run make
```

## 使い方

1. Pixel Codexを起動します。
2. 上部の`WORKSPACE`でCodexに作業させるフォルダを選びます。
3. `接続`を押します。
4. 自動検出できない場合は、右端の`…`から`codex.exe`を指定します。
5. `NEW MISSION`へ指示を書き、`開始`を押します。
6. オフィスまたは一覧でエージェントを選び、右側から追加指示や停止を行います。
7. `回答・質問`でAIのメッセージを確認し、質問が届いた場合は同じパネルから回答します。
8. `社員名簿`で利用するエージェントを雇用します。雇用した構成は次の新規プロジェクトから統括エージェントへ渡されます。
9. `成果物`の`開く`で完成したファイルを表示します。`図書館`では作業フォルダ内を移動し、任意のファイルやフォルダを開けます。
10. 上部の`WORKSPACE`を押すと最近接続したフォルダを再選択できます。不要な履歴は右側の`×`で削除できます。

接続中に`WORKSPACE`を変更すると、現在のApp Serverとスレッドを終了し、選択したフォルダで自動的に再接続します。

Codex CLIは同梱していません。端末にCodex CLIがインストールされ、ログイン済みであることが必要です。

## 構成

```text
src/
├─ codex/      App Serverプロセス・JSON-RPC通信
├─ game/       Phaserオフィス・エージェント表示
├─ stores/     Zustand状態管理・イベント変換
├─ App.tsx     React操作パネル
├─ index.ts    Electronメインプロセス・限定IPC
└─ preload.ts  contextBridge API
```

レンダラーにはNode.jsや任意IPCを公開していません。`contextIsolation`とsandboxを有効にし、操作単位の限定APIのみをpreloadから公開しています。

## 配布物

`npm run make`後、WindowsインストーラーとZIPが`out/make/`へ生成されます。コード署名と正式アイコンはリリース前に別途設定してください。
